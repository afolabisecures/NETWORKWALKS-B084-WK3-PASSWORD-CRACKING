# NETWORKWALKS-B084-WK3-PASSWORD-CRACKING
Networkwalks Internship Week 3 Project Password Cracking 

## Overview

For my **3rd week of cybersecurity internship**, I worked on password cracking using **John the Ripper (Windows version)** and the password-cracking tools provided by the internship company.

The project helped me gain practical experience in password security, hash cracking, and understanding how weak passwords can be exposed through password-cracking techniques.

## Tools Used

- **John the Ripper — Windows Version**
- **Internship Company's Password Cracking Tools**

## What I Learned

- The basics of password cracking and hash recovery
- How to use John the Ripper on Windows
- How password hashes can be tested against password lists
- The importance of strong passwords and secure authentication practices
- Practical application of password-cracking techniques in an authorized environment
