# Week 3 Internship Project — Password Cracking

## Overview

As part of my **3rd week cybersecurity internship project**, I worked on password cracking using **John the Ripper (Windows version)** and the internship company's password-cracking tools.

The project provided hands-on experience with how password hashes can be tested and recovered, while highlighting the importance of strong password security and proper authentication controls.

## Tools Used

- **John the Ripper — Windows Version**
- Internship Company's Password Cracking Tools
